## ✨ Key Features

- **Interactive Split-Identity Hero:** Dual hover states & trailing cursor allowing clients to explore both creative video editing and software engineering disciplines.
- **Categorized Video & Project Archive:** Filterable portfolio spanning Documentaries, Commercials, Shorts & Reels (9:16), UGC Ads, Motion Graphics, AI Animation, and Live Web/App Projects.
- **Embedded Modal Player:** Instant high-res YouTube & Vimeo video playback directly within the site.
- **Client-Centric Solutions & Deliverables:** Comprehensive service breakdown detailing exact deliverables, production toolkits, and a transparent 4-step collaboration workflow.
- **Direct Multi-Channel Inquiry System:** Streamlined project inquiry form supporting direct **WhatsApp** messaging and **Email** client integration with pre-formatted project briefs.
- **Brutalist Editorial Aesthetic:** Custom corner bracket frames (`BracketFrame`), precise grid overlays, and crisp typography with dark mode contrast.

## 💻 Running Locally

To run this project on your local machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/zabid-coder/zabid-portfolio-website.git
   ```
2. Navigate into the project directory:
   ```bash
   cd zabid-portfolio-website
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
